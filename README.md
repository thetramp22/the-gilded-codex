# The Gilded Codex

The Gilded Codex is Wargaming Hobby Catalog app. It is designed to help users track their collections of wargaming miniatures, paints, and tools to keep their hobby oraganized.

## Hobby Catalog — Development Roadmap

### PROJECT GOAL

A complete, deployed full-stack hobby catalog
A Django REST API backed by PostgreSQL, with a React/TypeScript interface for managing a private collection of miniatures and supplies.

**Backend**: Python · Django · DRF

**Database**: PostgreSQL

**Frontend**: React · TypeScript · Vite

**Development**: Git · Docker · Automated tests

## Roadmap at a glance
